


# Insurance Data Analysis Dashboard

## Tools Used
- Power BI
- Power Query
- DAX

## Project Overview
Developed an interactive Power BI dashboard to analyze insurance data, track claim performance, and generate business insights through data visualization and modeling.

## Data Processing
- Imported data from MSSQL Server into Power BI
- Performed data cleaning and transformation using Power Query
- Applied data profiling techniques to ensure data quality and consistency

## Data Modeling
- Built relationships between tables for efficient data analysis
- Structured the data model for better performance and filtering

## Key Features
- Created KPIs to track claim performance and business metrics
- Added slicers for dynamic filtering and user interaction
- Designed multiple visuals including:
  - Card visuals
  - Multi-row cards
  - Ribbon charts
  - Bar charts
  - Line charts
  - Donut charts
  - Matrix visuals

## Advanced Features
- Implemented drill-through functionality for detailed insights
- Applied Row-Level Security (RLS) to restrict data access
- Configured scheduled refresh for automatic data updates
- Published reports to Power BI Service

## Insights
- Identified claim trends and performance patterns
- Highlighted key business metrics for decision-making
- Provided interactive reports for deeper analysis
